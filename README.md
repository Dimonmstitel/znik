## Описание 
Программа читает базы белков из sequences.txt, выполняет команды 
search / diff / mode из commands.txt и пишет результат в genedata.txt. 
Поддерживается RLE-кодирование аминокислотных цепочек. 
 
## Запуск 
    dotnet run -- sequences.1.txt commands.1.txt genedata.txt
