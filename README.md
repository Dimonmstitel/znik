# Лабораторная работа №1. Генетический поиск

**Студент:** дима 
**Группа:** сдп-пмат-251

## Описание

Программа читает базу белков из `sequences.txt`, выполняет команды
`search`, `diff`, `mode` из `commands.txt` и записывает результат
в `genedata.txt`. Поддерживается RLE-кодирование аминокислотных цепочек.

## Запуск

    dotnet run -- sequences.1.txt commands.1.txt genedata.txt

## Файлы

- `Program.cs` — исходный код
- `sequences.*.txt` — данные о белках
- `commands.*.txt` — команды
- `genedata.*.txt` — эталонные результаты
